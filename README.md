Procedure:

Example:

Straightforward Prompts:

• "Define photosynthesis in one sentence."

"List three advantages of electric vehicles."

Tabular Format Prompting:

• "Compare and contrast AC and DC current in a table."

• "Provide a table listing five programming languages, their paradigms, and one use case each."

• "Why is climate change a global concern? Explain how greenhouse gases contribute to global warming."

• "The capital of France is ____."

1. Straightforward Prompts

Explanation:
Straightforward prompts are direct and simple instructions given to the AI. They clearly specify the required information without additional context. These prompts are useful when quick and precise answers are needed.

Scenario 1: Education

Prompt:
• "Define artificial intelligence in one sentence."

Example Output:
Artificial Intelligence is a technology that enables machines to mimic human intelligence and perform tasks such as learning and decision-making.

Scenario 2: Health

Prompt:
• "List three benefits of drinking enough water daily."

Example Output:

Maintains body temperature
Improves digestion
Keeps the body hydrated
2. Tabular Format Prompting

Explanation:
Tabular format prompting requests information in a structured table form. It helps compare data clearly and improves readability.

Scenario 1: Networking

Prompt:
• "Compare Wi-Fi and Bluetooth in a table based on range, speed, and usage."

Example Output:

Feature	Wi-Fi	Bluetooth
Range	Long	Short
Speed	High	Moderate
Usage	Internet connectivity	Device pairing
Scenario 2: Programming

Prompt:
• "Provide a table listing five programming languages, their paradigms, and one application."

Example Output:

Language	Paradigm	Application
Python	Object Oriented	AI development
Java	Object Oriented	Mobile apps
C	Procedural	System software
3. Preceding Question Prompting

Explanation:
Preceding question prompting starts with a guiding question and then asks for an explanation. It helps generate detailed and contextual responses.

Scenario 1: Environment

Prompt:
• "Why is renewable energy important? Explain how solar energy helps reduce pollution."

Example Output:
Renewable energy reduces dependence on fossil fuels. Solar energy generates electricity without harmful emissions and helps reduce environmental pollution.

Scenario 2: Cyber Security

Prompt:
• "Why is online privacy important? Explain methods to protect personal information."

Example Output:
Online privacy protects user data from misuse. Strong passwords, two-factor authentication, and avoiding suspicious links help improve security.

4. Missing Word Prompting

Explanation:
Missing word prompting provides incomplete statements where the AI fills in the missing information. This type is commonly used in educational exercises and quizzes.

Scenario 1: Geography

Prompt:
• "The largest desert in the world is ____."

Example Output:
Sahara

Scenario 2: Computer Science

Prompt:
• "HTML stands for HyperText Markup ____."

Example Output:
Language

OUTPUT:

Different prompt types were created and tested for multiple use cases. Examples and expected outputs were included to understand the behavior and structure of each prompting technique.

RESULT:

Different prompting techniques such as straightforward prompting, tabular prompting, preceding question prompting, and missing word prompting were successfully explored with two scenarios each. The experiment demonstrated that prompt structure affects the quality, clarity, and usefulness of AI-generated responses.
